## 一、基础理论术语

### 阴阳类

| 术语 | 解释 |
|-----|------|
| 阴阳 | 对立统一的两种属性，阴主静、寒、内、物质；阳主动、热、外、功能 |
| 阴阳对立 | 阴阳双方相互排斥、相互制约 |
| 阴阳互根 | 阴阳相互依存，互为根本 |
| 阴阳消长 | 阴阳双方此消彼长的动态变化 |
| 阴阳转化 | 阴阳在一定条件下相互转化 |
| 阴阳平衡 | 阴阳协调平衡，是健康的基础 |
| 阴阳失调 | 阴阳失衡，是疾病的基本病机 |
| 阴虚 | 阴液不足，虚热内生 |
| 阳虚 | 阳气不足，虚寒内生 |
| 阴盛 | 阴寒过盛，实寒证 |
| 阳盛 | 阳热过盛，实热证 |

### 五行类

| 术语 | 解释 |
|-----|------|
| 五行 | 木、火、土、金、水五种基本元素 |
| 五行相生 | 木→火→土→金→水→木，循环滋生 |
| 五行相克 | 木→土→水→火→金→木，循环制约 |
| 母子关系 | 生我者为母，我生者为子 |
| 相乘 | 克制太过，超过正常制约程度 |
| 相侮 | 反向克制，被克者反克主克者 |
| 五行配属 | 五行与五脏、五色、五味等的对应关系 |

### 藏象类

| 术语 | 解释 |
|-----|------|
| 藏象 | 内在脏腑及其外在表现 |
| 五脏 | 心、肝、脾、肺、肾，主藏精气 |

| 奇恒之腑 | 脑、髓、骨、脉、胆、女子胞 |
| 心主血脉 | 心推动血液在脉中运行 |
| 心主神明 | 心主宰精神意识思维活动 |

| 肝主藏血 | 肝贮藏和调节血液 |
| 脾主运化 | 脾消化转运水谷精微 |
| 脾主统血 | 脾统摄血液在脉中运行 |
| 肺主气 | 肺主呼吸之气和一身之气 |
| 肺主宣发肃降 | 肺气向上向外和向下向内 |
| 肾主藏精 | 肾贮藏先天和后天之精 |
| 肾主水 | 肾调节水液代谢 |
| 肾主纳气 | 肾摄纳肺吸入的清气 |

### 气血津液类

| 术语 | 解释 |
|-----|------|
| 气 | 构成和维持人体生命活动的精微物质 |
| 血 | 运行于脉中的红色液体，营养全身 |
| 津液 | 机体正常水液的总称 |
| 元气 | 先天之气，生命活动的原动力 |
| 宗气 | 积于胸中之气，主呼吸和行血 |
| 营气 | 行于脉中，营养全身 |
| 卫气 | 行于脉外，护卫肌表 |
| 气机 | 气的升降出入运动 |
| 气化 | 气的运动产生的各种变化 |
| 气滞 | 气的运行不畅 |
| 气逆 | 气的上升太过或下降不及 |
| 气陷 | 气的上升不及或下降太过 |
| 气闭 | 气郁闭于内，不能外达 |
| 气脱 | 气大量外脱，功能衰竭 |
| 血虚 | 血液不足或功能减退 |
| 血瘀 | 血液运行不畅或瘀滞 |
| 血热 | 热入血分，迫血妄行 |
| 津液不足 | 津液亏少，滋润功能减退 |

| 络脉 | 经络的分支，横行浅表 |

| 得气 | 针刺后产生的酸麻胀重感 |
| 循经感传 | 针刺后沿经脉路线的传导感 |

## 六、常见证候术语

### 八纲证候

| 证候 | 主要表现 |
|-----|---------|
| 表证 | 恶寒发热，头身疼痛，脉浮 |
| 里证 | 但热不寒或但寒不热，脏腑症状明显 |
| 寒证 | 恶寒喜暖，口淡不渴，面色苍白，肢冷蜷卧 |
| 热证 | 发热喜凉，口渴喜冷饮，面红目赤，烦躁不宁 |
| 虚证 | 面色淡白或萎黄，精神萎靡，身疲乏力 |
| 实证 | 发热，腹胀痛拒按，胸闷烦躁，呼吸气粗 |
| 阴证 | 符合阴的属性：里、寒、虚 |
| 阳证 | 符合阳的属性：表、热、实 |
