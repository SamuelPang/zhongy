# 推荐书目

> 中医自学必备参考书籍

---

## 一、入门级（★）

适合完全零基础，建立中医基本概念

### 通俗读物

| 书名 | 作者 | 说明 |
|-----|------|------|
| 《中医入门》 | 秦伯未 | 中医入门经典，简明易懂 |
| 《名老中医之路》 | 周凤梧等 | 名中医学习经验，启发很大 |
| 《求医不如求己》 | 中里巴人 | 通俗易懂，适合养生爱好者 |
| 《人体使用手册》 | 吴清忠 | 现代视角解读中医理念 |
| 《中医养生常识》 |  various | 各类养生常识读物 |

### 学习建议
- 先读 1-2 本通俗读物，建立兴趣
- 了解中医基本理念和方法
- 不要急于深入，打好兴趣基础

## 五、按学习路径推荐

### 路径一：养生保健（3-6 个月）

```
1. 《中医入门》- 秦伯未
2. 《中医基础理论》- 教材
3. 《中医养生常识》类
```

## 八、学习建议

### 阅读顺序

```
入门读物 → 基础教材 → 临床教材 → 经典原著 → 专深研究
```

### 阅读方法

1. **教材为主，经典为辅**：先用教材打基础，再读经典
2. **反复研读**：中医理论需要反复体悟
3. **做笔记**：整理知识框架，记录心得
4. **结合实际**：联系生活，观察体会
5. **循序渐进**：不要急于求成，打好基础最重要

### 注意事项

⚠️ **安全提示**：
- 自学以养生保健为主
- 涉及疾病治疗需咨询专业医师
- 有毒药物需专业指导
- 针灸等操作需专业培训
