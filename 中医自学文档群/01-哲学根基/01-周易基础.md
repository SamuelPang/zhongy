# 01 周易基础

> 阴阳、八卦、五行——中医理论的哲学本源

- 理解阴阳的基本概念和属性
- 掌握八卦的基本象义

- 为学习中医理论打下哲学基础

## 二、核心概念

### 2.1 什么是《周易》

《周易》是中国古代最重要的哲学经典之一，被誉为"群经之首，大道之源"。

- **周**：周遍、周流不息
- **易**：简易、变易、不易（三层含义）
- **核心思想**：通过阴阳变化揭示宇宙万物的运行规律

### 2.2 中医与《周易》的关系

> **"医易同源，理无二致"**

中医理论体系的形成深受《周易》哲学思想影响：
- 阴阳学说是中医理论的核心
- 五行学说贯穿生理、病理、诊断、治疗
- 象数思维影响脉诊、针灸、方药配伍

## 三、阴阳学说基础

### 3.1 阴阳的概念

**阴阳**是对自然界相互对立又相互关联的两种事物或现象的概括。

| 阴 | 阳 |
|---|---|
| 黑暗 | 光明 |
| 寒冷 | 温热 |
| 内向 | 外向 |
| 下降 | 上升 |
| 静止 | 运动 |
| 物质 | 功能 |
| 抑制 | 兴奋 |
| 收敛 | 发散 |

### 3.2 阴阳的属性

**阳的属性**：
- 天、日、火、水（表面）、气
- 男、上、外、左
- 热、温、升、动、强

**阴的属性**：
- 地、月、水、土（内里）、形
- 女、下、内、右
- 寒、凉、降、静、弱

### 3.3 阴阳的四种关系

#### ① 阴阳对立
```
天 ←→ 地
日 ←→ 月
热 ←→ 寒
上 ←→ 下
```

#### ② 阴阳互根
> "阴在内，阳之守也；阳在外，阴之使也。"
> ——《素问·阴阳应象大论》

- 阴是阳的基础，阳是阴的表现
- 没有阴就没有阳，没有阳也没有阴
- **例**：物质（阴）是功能（阳）的基础，功能是物质的表现

#### ③ 阴阳消长
```
昼夜变化：
白天（阳长阴消）→ 黄昏（阴阳平衡）→ 夜晚（阴长阳消）→ 黎明（阴阳平衡）

四季变化：
春→夏（阳长阴消）→ 秋→冬（阴长阳消）
```

#### ④ 阴阳转化
> "重阴必阳，重阳必阴"
> "寒极生热，热极生寒"

- 物极必反，阴阳在一定条件下可以相互转化
- **例**：高热（阳）至极可能出现四肢厥冷（阴）的假象

### 3.4 阴阳在中医学中的应用

| 应用方面 | 阴 | 阳 |
|---------|---|---|
| 人体结构 | 脏腑之里、下部、精血津液 | 脏腑之表、上部、功能活动 |
| 生理功能 | 物质基础 | 功能表现 |
| 病理变化 | 阴虚、阴盛 | 阳虚、阳盛 |
| 诊断辨证 | 里证、寒证、虚证 | 表证、热证、实证 |
| 治疗原则 | 滋阴、散寒 | 补阳、清热 |

## 四、八卦基础

### 4.1 八卦的构成

八卦由阴爻（--）和阳爻（—）组合而成，每卦三爻。

```
乾卦 ☰  坤卦 ☷  震卦 ☳  巽卦 ☴
坎卦 ☵  离卦 ☲  艮卦 ☶  兑卦 ☱
```

### 4.2 八卦的基本象义

| 卦名 | 卦象 | 自然 | 人体 | 属性 | 五行 |
|-----|------|-----|------|-----|-----|
| **乾** | ☰ | 天 | 头、首、骨 | 刚健 | 金 |
| **坤** | ☷ | 地 | 腹、脾、肉 | 柔顺 | 土 |
| **震** | ☳ | 雷 | 足、肝 | 动 | 木 |
| **巽** | ☴ | 风 | 股、胆 | 入 | 木 |
| **坎** | ☵ | 水 | 耳、肾、血 | 陷、险 | 水 |
| **离** | ☲ | 火 | 目、心、血 | 明、丽 | 火 |
| **艮** | ☶ | 山 | 手、胃、背 | 止 | 土 |
| **兑** | ☱ | 泽 | 口、肺、皮肤 | 悦 | 金 |

### 4.3 八卦与人体对应

```
        乾（头）
          │
艮（手）──┼──兑（口）
          │
    巽────┼────震（足）
          │
        坤（腹）
```

**详细说明**：
- **乾卦**：头部疾病、骨骼问题
- **坤卦**：腹部疾病、脾胃问题
- **震卦**：足部疾病、肝病患者
- **巽卦**：大腿疾病、胆病患者
- **坎卦**：耳部疾病、肾脏问题
- **离卦**：眼部疾病、心脏问题
- **艮卦**：手部疾病、胃部问题
- **兑卦**：口部疾病、肺病患者

### 4.4 八卦在中医中的应用

1. **疾病分类**：根据症状部位归类病证
2. **针灸取穴**：结合八卦方位选择穴位
3. **时间医学**：子午流注与八卦时辰对应

## 五、五行学说基础

### 5.1 五行的概念

**五行**：木、火、土、金、水五种基本元素及其运动变化。

> "五行者，金木水火土也，更贵更贱，以知生死，以决成败。"
> ——《史记·扁鹊仓公列传》

### 5.2 五行的特性

| 五行 | 特性 | 引申含义 |
|-----|------|---------|
| **木** | 曲直 | 生长、升发、条达、舒畅 |
| **火** | 炎上 | 温热、升腾、光明、活跃 |
| **土** | 稼穑 | 生化、承载、受纳、调和 |
| **金** | 从革 | 清洁、肃降、收敛、变革 |
| **水** | 润下 | 寒凉、滋润、向下、闭藏 |

### 5.3 五行与事物的配属

五行学说将自然界和人体的各种事物归纳为五大系统：

| 五行 | 五脏 | 六腑 | 五官 | 形体 | 情志 | 五色 | 五味 | 五季 |
|-----|-----|-----|-----|-----|-----|-----|-----|-----|
| **木** | 肝 | 胆 | 目 | 筋 | 怒 | 青 | 酸 | 春 |
| **火** | 心 | 小肠 | 舌 | 脉 | 喜 | 赤 | 苦 | 夏 |
| **土** | 脾 | 胃 | 口 | 肉 | 思 | 黄 | 甘 | 长夏 |
| **金** | 肺 | 大肠 | 鼻 | 皮 | 忧 | 白 | 辛 | 秋 |
| **水** | 肾 | 膀胱 | 耳 | 骨 | 恐 | 黑 | 咸 | 冬 |

### 5.4 五行的生克关系

#### 相生关系（母子关系）

```
    木
   ╱  ╲
  ↓    ↓
 水    火
  ↑    ↓
 金 ← 土
```

**相生顺序**：木 → 火 → 土 → 金 → 水 → 木（循环往复）

**相生规律**：
- **木生火**：木能燃烧生火
- **火生土**：火烧后成灰归于土
- **土生金**：土中埋藏金属
- **金生水**：金属熔化成液体（或金属表面凝结水珠）
- **水生木**：水滋养树木生长

**母子关系**：
- 生我者为母，我生者为子
- 例：木生火，则木为火之母，火为木之子

#### 相克关系（制约关系）

```
    木
   ╱  ╲
  ↓    ↑
 土    火
  ↑    ↓
 金 ← 水
```

**相克顺序**：木 → 土 → 水 → 火 → 金 → 木（循环制约）

**相克规律**：
- **木克土**：树木根系能破土
- **土克水**：土能挡水、吸水
- **水克火**：水能灭火
- **火克金**：火能熔金
- **金克木**：金属工具能伐木

### 5.5 五行的异常关系

#### 相乘（过度克制）

相乘 = 克得太过，超过正常制约程度

```
正常：木 → 土
相乘：木太过 →→→ 土（木乘土）
```

**常见相乘**：
- 木乘土：肝气过旺伤脾
- 土乘水：脾湿过重伤肾
- 水乘火：寒水过盛伤心阳
- 火乘金：心火过旺伤肺
- 金乘木：肺气过肃伤肝

#### 相侮（反向克制）

相侮 = 反向克制，本来被克的反过来克主克者

```
正常：木 → 土
相侮：土 →→→ 木（土侮木）
```

**常见相侮**：
- 土侮木：脾病及肝
- 水侮土：肾病及脾
- 火侮水：心病及肾
- 金侮火：肺病及心
- 木侮金：肝病及肺

### 5.6 五行在中医中的应用

#### 生理应用

1. **说明脏腑功能**：
   - 肝属木，主疏泄，喜条达
   - 心属火，主血脉，主神明
   - 脾属土，主运化，为后天之本
   - 肺属金，主气司呼吸，主宣发肃降
   - 肾属水，主藏精，为先天之本

2. **说明脏腑关系**：
   - 肝肾同源（水生木）
   - 心脾相生（火生土）
   - 肺肾相生（金生水）

#### 病理应用

1. **说明疾病传变**：
   - 母病及子：肾病及肝（水生木）
   - 子病及母：心病及肝（木生火）
   - 相乘传变：肝病传脾（木乘土）
   - 相侮传变：肝病传肺（木侮金）

2. **诊断疾病**：
   - 面青、喜酸、脉弦 → 肝病（木）
   - 面赤、口苦、脉洪 → 心病（火）
   - 面黄、味甘、脉缓 → 脾病（土）
   - 面白、辛味、脉浮 → 肺病（金）
   - 面黑、味咸、脉沉 → 肾病（水）

#### 治疗应用

1. **确定治疗原则**：
   - 虚则补其母：肝虚补肾（水生木）
   - 实则泻其子：肝实泻心（木生火）

2. **常用治法**：
   - **滋水涵木法**：滋肾阴养肝阴
   - **益火补土法**：温肾阳健脾阳
   - **培土生金法**：健脾补肺
   - **金水相生法**：补肺肾之阴
   - **抑木扶土法**：疏肝健脾

## 七、学习要点

### 重点掌握

1. ✅ 阴阳的基本属性和四种关系（对立、互根、消长、转化）
2. ✅ 八卦的基本象义，尤其是与人体对应的部分
3. ✅ 五行的生克关系和异常关系（相乘、相侮）
4. ✅ 五行与五脏、五色、五味、五季的配属

### 难点提示

⚠️ **阴阳互根**：理解"阴中有阳，阳中有阴"
- 例：白天（阳）中有上午（阳中之阳）和下午（阳中之阴）
- 例：夜晚（阴）中有前半夜（阴中之阴）和后半夜（阴中之阳）

⚠️ **五行生克与临床结合**：
- 不仅要记住生克关系
- 更要理解在病理传变中的实际意义
- 例：为什么"见肝之病，知肝传脾"？（木乘土）

> 木生火，火生土
