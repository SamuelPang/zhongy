# 17 外治法入门

> 艾灸、拔罐、刮痧、按摩

## 一、学习目标

- 了解常用外治法的原理
- 掌握基本操作方法
- 能够安全运用外治法保健

---

## 二、外治法概述

### 2.1 什么是外治法

**外治法**：通过体表施治，达到防治疾病目的的方法。

**特点**：
- 操作简单
- 副作用小
- 适合家庭保健

### 2.2 常用外治法

| 方法 | 原理 | 适用 |
|-----|------|------|
| 艾灸 | 温通经络，散寒除湿 | 寒证、虚证 |
| 拔罐 | 活血化瘀，祛风散寒 | 痹证、痛证 |
| 刮痧 | 清热解毒，活血化瘀 | 热证、表证 |
| 按摩 | 疏通经络，调和气血 | 各种证候 |

## 三、艾灸

### 3.1 艾灸的原理

**艾灸**：用艾叶制成的艾绒燃烧，温热刺激穴位。

**作用**：
- 温通经络
- 散寒除湿
- 扶正祛邪
- 防病保健

### 3.2 艾灸的方法

#### 温和灸

**操作**：
1. 点燃艾条
2. 距皮肤 2-3cm
3. 温热为度
4. 每穴 5-10 分钟

**适用**：各种虚寒证

#### 雀啄灸

**操作**：
1. 点燃艾条
2. 上下移动如雀啄
3. 每穴 3-5 分钟

**适用**：急症

#### 隔姜灸

**操作**：
1. 生姜切片（厚 2-3mm）
2. 刺数孔
3. 上置艾炷点燃
4. 每穴 3-5 壮

**适用**：胃寒呕吐、腹痛泄泻

### 3.3 常用保健穴位

| 穴位 | 定位 | 功效 |
|-----|------|------|
| 足三里 | 犊鼻下 3 寸 | 健脾和胃，强壮保健 |
| 关元 | 脐下 3 寸 | 补肾固本，温阳 |
| 气海 | 脐下 1.5 寸 | 补气益气 |
| 神阙 | 脐中 | 温阳救逆，利水固脱 |
| 中脘 | 脐上 4 寸 | 健脾和胃 |
| 大椎 | 第 7 颈椎棘突下 | 清热解表，强壮 |
| 肾俞 | 第 2 腰椎棘突下旁开 1.5 寸 | 补肾壮阳 |
| 命门 | 第 2 腰椎棘突下 | 温补肾阳 |

### 3.4 艾灸注意事项

**禁忌**：
- 实热证禁用
- 阴虚发热慎用
- 面部、大血管处禁用
- 孕妇腹部禁用
- 过饥过饱不宜

**注意事项**：
- 注意防火安全
- 避免烫伤
- 灸后饮温水
- 灸后避风寒

## 四、拔罐

### 4.1 拔罐的原理

**拔罐**：利用负压吸附体表，造成局部充血。

**作用**：
- 活血化瘀
- 祛风散寒
- 消肿止痛
- 祛湿解毒

### 4.2 拔罐的方法

#### 火罐

**操作**：
1. 用镊子夹酒精棉球点燃
2. 在罐内绕一圈
3. 迅速扣在皮肤上
4. 留罐 5-15 分钟

**适用**：风寒湿痹、腰背疼痛

#### 抽气罐

**操作**：
1. 将罐扣在皮肤上
2. 用抽气筒抽气
3. 留罐 5-15 分钟

**适用**：各种证候（安全方便）

#### 走罐

**操作**：
1. 在皮肤和罐口涂润滑油
2. 将罐扣在皮肤上
3. 来回推动
4. 至皮肤潮红

**适用**：大面积肌肉酸痛

### 4.3 常用拔罐部位

| 部位 | 适用 |
|-----|------|
| 背部膀胱经 | 脏腑疾病 |
| 大椎穴 | 感冒发热 |
| 肺俞穴 | 咳嗽哮喘 |
| 肾俞穴 | 腰膝酸软 |
| 阿是穴 | 局部疼痛 |

### 4.4 拔罐注意事项

**罐印意义**：
- 紫黑：瘀血重
- 暗红：寒湿重
- 鲜红：热证
- 水泡：湿重
- 无变化：正常或病轻

**禁忌**：
- 皮肤破损禁用
- 出血倾向禁用
- 高热抽搐禁用
- 孕妇腹部禁用
- 过饥过饱不宜

**注意事项**：
- 留罐时间不宜过长
- 起罐时按压皮肤
- 拔罐后避风寒
- 同一部位不宜频繁拔罐

## 五、刮痧

### 5.1 刮痧的原理

**刮痧**：用刮痧板在体表刮拭，使皮肤出现瘀斑。

**作用**：
- 清热解毒
- 活血化瘀
- 舒筋通络
- 祛邪外出

### 5.2 刮痧的方法

**操作**：
1. 在皮肤上涂刮痧油
2. 刮痧板与皮肤成 45°角
3. 单向刮拭
4. 至出现瘀斑为度

**顺序**：
- 先头面，后四肢
- 先背部，后腹部
- 先左后右
- 先上后下

### 5.3 常用刮痧部位

| 部位 | 适用 |
|-----|------|
| 颈项部 | 感冒、头痛、颈痛 |
| 背部膀胱经 | 脏腑疾病 |
| 肘窝、腘窝 | 高热、中暑 |
| 胸部 | 咳嗽、胸闷 |
| 腹部 | 腹痛、消化不良 |

### 5.4 刮痧注意事项

**痧象意义**：
- 鲜红：热证
- 紫暗：瘀血
- 青紫：寒凝
- 无痧：正常或病轻

**禁忌**：
- 皮肤破损禁用
- 出血倾向禁用
- 浮肿禁用
- 孕妇腹部禁用
- 过饥过饱不宜

**注意事项**：
- 刮痧力度适中
- 刮痧后饮温水
- 刮痧后避风寒
- 痧退后再刮（3-7 天）

## 六、按摩

### 6.1 按摩的原理

**按摩**：用手在体表施以各种手法。

**作用**：
- 疏通经络
- 调和气血
- 滑利关节
- 理筋整复

### 6.2 基本手法

#### 推法

**操作**：用指、掌沿直线推动

**作用**：理气活血，舒筋通络

#### 拿法

**操作**：用拇指和其余四指相对用力捏拿

**作用**：祛风散寒，开窍止痛

#### 按法

**操作**：用指、掌按压穴位或部位

**作用**：开通闭塞，活血止痛

#### 摩法

**操作**：用手掌在体表环形摩擦

**作用**：和中理气，消积导滞

#### 揉法

**操作**：用手指或手掌在体表揉动

**作用**：活血止痛，消肿散结

#### 捏法

**操作**：用拇指和食指捏拿皮肤

**作用**：调和气血，疏通经络

#### 滚法

**操作**：用手背在体表滚动

**作用**：舒筋活络，活血止痛

#### 搓法

**操作**：用双手夹住肢体搓动

**作用**：调和气血，舒筋活络

### 6.3 常用保健按摩

#### 头部按摩

**操作**：
1. 梳头：从前额梳到后脑
2. 按揉太阳穴
3. 叩击头顶

**功效**：醒脑明目，缓解头痛

#### 面部按摩

**操作**：
1. 搓热双手
2. 从下向上抚摩面部
3. 按揉穴位（迎香、睛明等）

**功效**：美容养颜，预防感冒

#### 腹部按摩

**操作**：
1. 搓热双手
2. 顺时针摩腹 36 次
3. 再逆时针摩腹 36 次

**功效**：健脾和胃，通便

#### 腰部按摩

**操作**：
1. 搓热双手
2. 上下搓腰至发热
3. 按揉肾俞、命门

**功效**：补肾壮腰，缓解腰痛

#### 足部按摩

**操作**：
1. 搓热双脚
2. 按揉涌泉穴
3. 按压足三里

**功效**：引火归元，强壮保健

### 6.4 按摩注意事项

**禁忌**：
- 皮肤破损禁用
- 骨折禁用
- 肿瘤部位禁用
- 孕妇腹部禁用
- 过饥过饱不宜

**注意事项**：
- 力度适中，以舒适为度
- 按摩前剪指甲
- 按摩后饮温水
- 注意保暖

## 七、外治法组合应用

### 7.1 感冒

**风寒感冒**：
- 艾灸：大椎、风门
- 拔罐：背部膀胱经
- 刮痧：颈项部
- 按摩：迎香、合谷

**风热感冒**：
- 刮痧：大椎、曲池、委中
- 按摩：合谷、列缺

### 7.2 胃痛

**胃寒痛**：
- 艾灸：中脘、足三里
- 按摩：中脘、内关

**胃热痛**：
- 刮痧：胃俞、足三里
- 按摩：内关、足三里

### 7.3 腰痛

**寒湿腰痛**：
- 艾灸：肾俞、命门、腰阳关
- 拔罐：腰部阿是穴
- 按摩：腰部滚法

**肾虚腰痛**：
- 艾灸：肾俞、命门、关元
- 按摩：腰部搓热，按揉肾俞

### 7.4 失眠

**心脾两虚**：
- 艾灸：心俞、脾俞、足三里
- 按摩：神门、三阴交、涌泉

**阴虚火旺**：
- 按摩：涌泉、太溪、神门
- 刮痧：心俞、肾俞
