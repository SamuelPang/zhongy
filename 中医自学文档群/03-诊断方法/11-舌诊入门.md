# 11 舌诊入门

> 观察舌象诊断疾病

## 一、学习目标

- 掌握舌诊的基本方法
- 熟悉正常舌象
- 能够识别常见异常舌象

---

## 二、舌诊概述

### 2.1 舌诊的意义

**舌诊**：观察舌质和舌苔的变化来诊断疾病的方法。

**舌与脏腑的关系**：
- 舌为心之苗
- 舌为脾之外候
- 舌根属肾
- 舌边属肝胆
- 舌中属脾胃

### 2.2 舌的分区

```
        舌尖（心肺）
           │
舌边（肝胆）┼─舌中（脾胃）
           │
        舌根（肾）
```

### 2.3 舌诊的方法

1. **光线**：自然光为宜
2. **姿势**：坐位或仰卧位
3. **伸舌**：舌体自然伸展，勿过度用力
4. **顺序**：先看舌苔，再看舌质；先看舌尖，再看舌根

---

## 三、正常舌象

### 3.1 正常舌象

**淡红舌，薄白苔**

| 项目 | 正常表现 |
|-----|---------|
| 舌质 | 淡红润泽 |
| 舌苔 | 薄白均匀 |
| 舌体 | 大小适中，柔软灵活 |

### 3.2 正常舌象的意义

- 气血充足
- 胃气旺盛
- 身体健康

## 四、舌质诊察

### 4.1 舌色

| 舌色 | 表现 | 主病 |
|-----|------|------|
| 淡白舌 | 比正常浅淡 | 气血两虚、阳虚 |
| 红舌 | 比正常红 | 热证 |
| 绛舌 | 深红 | 热入营血 |
| 紫舌 | 青紫 | 瘀血 |
| 青舌 | 如青筋暴露 | 寒凝血瘀 |

**详细**：

**淡白舌**：
- 表现：舌色比正常浅淡，甚至无血色
- 主病：气血两虚、阳虚
- 兼症：面色苍白、乏力、畏寒

**红舌**：
- 表现：舌色较正常红
- 主病：热证
- 分类：
  - 舌红苔黄：实热
  - 舌红少苔：虚热

**绛舌**：
- 表现：深红色
- 主病：热入营血
- 兼症：高热、神昏、斑疹

**紫舌**：
- 表现：舌色青紫或有瘀斑
- 主病：瘀血
- 分类：
  - 紫而干燥：热盛血瘀
  - 紫而湿润：寒凝血瘀

### 4.2 舌形

| 舌形 | 表现 | 主病 |
|-----|------|------|
| 老嫩 | 纹理粗糙 | 实证 |
|  | 纹理细腻 | 虚证 |
| 胖瘦 | 舌体胖大 | 脾虚湿盛 |
|  | 舌体瘦薄 | 气血不足 |
| 点刺 | 舌有红点或芒刺 | 热盛 |
| 裂纹 | 舌面有裂纹 | 阴血不足 |
| 齿痕 | 舌边有齿痕 | 脾虚湿盛 |

### 4.3 舌态

| 舌态 | 表现 | 主病 |
|-----|------|------|
| 强硬 | 舌体强硬，活动不灵 | 热入心包或中风 |
| 痿软 | 舌体软弱无力 | 气血两虚或阴液亏损 |
| 颤动 | 舌体颤抖 | 肝风内动 |
| 歪斜 | 舌体偏向一侧 | 中风或中风先兆 |
| 吐弄 | 舌常伸出口外 | 心脾有热 |
| 短缩 | 舌体卷短 | 危重证候 |

## 五、舌苔诊察

### 5.1 苔色

| 苔色 | 表现 | 主病 |
|-----|------|------|
| 白苔 | 苔色白 | 表证、寒证 |
| 黄苔 | 苔色黄 | 热证、里证 |
| 灰黑苔 | 苔色灰黑 | 热极或寒极 |

**详细**：

**白苔**：
- 表现：苔色白
- 主病：表证、寒证
- 分类：
  - 薄白苔：正常或表证初起
  - 白厚苔：寒湿或食积
  - 白滑苔：寒湿
  - 白燥苔：燥热

**黄苔**：
- 表现：苔色黄
- 主病：热证、里证
- 分类：
  - 薄黄苔：表热或里热轻
  - 黄厚苔：里热重
  - 黄燥苔：热盛伤津
  - 黄腻苔：湿热

**灰黑苔**：
- 表现：苔色灰或黑
- 主病：热极或寒极
- 分类：
  - 灰黑干燥：热极伤阴
  - 灰黑湿润：阳虚寒盛

### 5.2 苔质

| 苔质 | 表现 | 主病 |
|-----|------|------|
| 厚薄 | 透过苔可见舌体 | 表证或病轻 |
|  | 透过苔不见舌体 | 里证或病重 |
| 润燥 | 苔湿润 | 津液未伤 |
|  | 苔干燥 | 津液已伤 |
| 腻腐 | 苔腻如油 | 湿浊、痰饮 |
|  | 苔腐如渣 | 食积、痰浊 |
| 剥落 | 苔部分脱落 | 胃气阴不足 |
| 有無 | 有苔 | 有胃气 |
|  | 无苔（镜面舌） | 胃气阴大伤 |

## 六、常见舌象组合

### 6.1 舌质 + 舌苔

| 舌象 | 主病 |
|-----|------|
| 淡白舌 + 白苔 | 寒证、虚证 |
| 红舌 + 黄苔 | 热证 |
| 红舌 + 少苔 | 阴虚内热 |
| 绛舌 + 黄燥苔 | 热入营血 |
| 紫舌 + 苔滑 | 寒凝血瘀 |
| 胖大舌 + 白腻苔 | 脾虚湿盛 |
| 裂纹舌 + 少苔 | 阴血不足 |

### 6.2 常见证候舌象

| 证候 | 舌象 |
|-----|------|
| 风寒表证 | 舌淡红，苔薄白 |
| 风热表证 | 舌边尖红，苔薄黄 |
| 脾胃虚寒 | 舌淡胖，苔白滑 |
| 脾胃湿热 | 舌红，苔黄腻 |
| 肝火上炎 | 舌红，苔黄 |
| 肾阴虚 | 舌红少苔 |
| 肾阳虚 | 舌淡胖，苔白滑 |
| 气血两虚 | 舌淡白，苔薄白 |
| 瘀血内阻 | 舌紫暗，或有瘀斑 |

## 七、舌诊注意事项

### 7.1 影响舌象的因素

| 因素 | 影响 |
|-----|------|
| 饮食 | 染苔（食物染色） |
| 药物 | 染苔、影响舌苔 |
| 时间 | 晨起苔厚，日间苔薄 |
| 年龄 | 小儿苔薄，老人苔厚 |
| 体质 | 先天舌象差异 |

### 7.2 避免误诊

1. **排除染苔**：询问饮食、用药史
2. **综合判断**：结合其他诊法
3. **动态观察**：多次观察舌象变化
