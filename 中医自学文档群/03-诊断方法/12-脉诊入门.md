# 12 脉诊入门

> 切脉诊断疾病

## 一、学习目标

- 了解脉诊的基本方法
- 掌握常见脉象的特征
- 理解脉象的临床意义

---

## 二、脉诊概述

### 2.1 脉诊的意义

**脉诊**：医生用手指切按患者脉搏，感知脉动形象来诊断疾病的方法。

**脉与脏腑的关系**：
- 心主血脉
- 脉为血之府
- 脉象反映脏腑气血盛衰

### 2.2 脉诊部位

**寸口脉**：腕后桡动脉搏动处

```
        寸      关      尺
        │       │       │
左手：  心      肝      肾（阴）
右手：  肺      脾      肾（阳）
```

### 2.3 脉诊方法

1. **时间**：清晨最佳，安静时为宜
2. **姿势**：坐位或仰卧位，手臂平放
3. **指法**：食、中、无名三指按寸关尺
4. **指力**：浮取、中取、沉取

## 三、常见脉象

### 3.1 浮脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 浮脉 | 轻取即得，重按稍减 | 表证 |
| 洪脉 | 脉来洪大，如波涛汹涌 | 热盛 |
| 濡脉 | 浮细无力 | 虚证、湿证 |

### 3.2 沉脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 沉脉 | 轻取不应，重按始得 | 里证 |
| 伏脉 | 重按推筋着骨始得 | 邪闭、厥证 |
| 牢脉 | 沉实大弦长 | 阴寒内积 |

### 3.3 迟脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 迟脉 | 一息不足四至（<60 次/分） | 寒证 |
| 缓脉 | 一息四至，来去弛缓 | 湿证、脾虚 |
| 涩脉 | 往来艰涩，如轻刀刮竹 | 血瘀、精伤 |

### 3.4 数脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 数脉 | 一息五至以上（>90 次/分） | 热证 |
| 疾脉 | 一息七至以上 | 阳极阴竭 |
| 促脉 | 数而时止，止无定数 | 阳盛实热 |

### 3.5 虚脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 虚脉 | 三部脉举按无力 | 虚证 |
| 细脉 | 脉细如线，应指明显 | 气血两虚、湿证 |
| 微脉 | 极细极软，似有似无 | 阳气衰微 |
| 弱脉 | 沉细无力 | 气血不足 |

### 3.6 实脉类

| 脉象 | 特征 | 主病 |
|-----|------|------|
| 实脉 | 三部脉举按有力 | 实证 |
| 滑脉 | 往来流利，如珠走盘 | 痰饮、食积、妊娠 |
| 弦脉 | 端直以长，如按琴弦 | 肝胆病、痛证、痰饮 |
| 紧脉 | 脉来紧张，如绞绳索 | 寒证、痛证 |

## 四、脉象主病总结

### 4.1 常见脉象主病

| 脉象 | 主病 |
|-----|------|
| 浮 | 表证 |
| 沉 | 里证 |
| 迟 | 寒证 |
| 数 | 热证 |
| 虚 | 虚证 |
| 实 | 实证 |
| 滑 | 痰饮、食积 |
| 弦 | 肝胆病、痛证 |
| 涩 | 血瘀、精伤 |
| 洪 | 热盛 |
| 细 | 气血虚、湿 |
| 弱 | 气血不足 |

### 4.2 脉证合参

**脉证相符**：脉象与证候一致，预后良好  
**脉证不符**：脉象与证候相反，预后较差

**例**：
- 表证见浮脉：相符
- 里证见浮脉：不符（可能为虚阳外越）
