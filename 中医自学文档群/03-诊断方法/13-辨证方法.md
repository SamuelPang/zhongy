# 13 辨证方法

> 中医辨证论治的核心

## 一、学习目标

- 了解辨证的概念
- 掌握八纲辨证的方法
- 熟悉脏腑辨证的基本思路

---

## 二、辨证概述

### 2.1 什么是辨证

**辨证**：将四诊收集的资料进行分析、综合，判断为某种"证"的过程。

**证**：疾病发展过程中某一阶段的病理概括。

**辨证论治**：
```
四诊 → 辨证 → 论治
```

### 2.2 证与病的区别

|  | 病 | 证 |
|---|---|---|
| 含义 | 疾病全过程 | 疾病某一阶段 |
| 特点 | 相对固定 | 动态变化 |
| 治疗 | 辨病治疗 | 辨证治疗 |

**同病异治**：同一种病，证候不同，治法不同  
**异病同治**：不同的病，证候相同，治法相同

## 三、八纲辨证

### 3.1 八纲的概念

**八纲**：阴、阳、表、里、寒、热、虚、实

**总纲**：阴阳

### 3.2 表里辨证

**表证**：
- 病位：肌表
- 特点：病程短，病情轻
- 表现：恶寒发热，头身疼痛，脉浮
- 多见于：外感病初期

**里证**：
- 病位：脏腑
- 特点：病程长，病情重
- 表现：但热不寒或但寒不热，脏腑症状明显
- 多见于：外感病后期或内伤病

**表里鉴别**：

| 项目 | 表证 | 里证 |
|-----|------|------|
| 寒热 | 恶寒发热并见 | 但寒不热或但热不寒 |
| 舌象 | 舌苔变化小 | 舌象变化明显 |
| 脉象 | 脉浮 | 脉沉 |

### 3.3 寒热辨证

**寒证**：
- 性质：寒邪致病或阳气不足
- 表现：
  - 恶寒喜暖
  - 口淡不渴
  - 面色苍白
  - 肢冷蜷卧
  - 小便清长
  - 大便稀溏
  - 舌淡苔白
  - 脉迟或紧

**热证**：
- 性质：热邪致病或阴液不足
- 表现：
  - 发热喜凉
  - 口渴喜冷饮
  - 面红目赤
  - 烦躁不宁
  - 小便短赤
  - 大便干结
  - 舌红苔黄
  - 脉数

**寒热鉴别**：

| 项目 | 寒证 | 热证 |
|-----|------|------|
| 寒热 | 恶寒喜暖 | 发热喜凉 |
| 口渴 | 口淡不渴 | 口渴喜冷饮 |
| 面色 | 苍白 | 红赤 |
| 四肢 | 肢冷 | 温热 |
| 二便 | 清长、稀溏 | 短赤、干结 |
| 舌象 | 淡白苔白 | 红苔黄 |
| 脉象 | 迟或紧 | 数 |

### 3.4 虚实辨证

**虚证**：
- 性质：正气不足
- 表现：
  - 面色淡白或萎黄
  - 精神萎靡
  - 身疲乏力
  - 心悸气短
  - 形寒肢冷或五心烦热
  - 自汗或盗汗
  - 舌淡或红少苔
  - 脉虚无力

**实证**：
- 性质：邪气亢盛
- 表现：
  - 发热
  - 腹胀痛拒按
  - 胸闷烦躁
  - 呼吸气粗
  - 痰涎壅盛
  - 大便秘结或热痢
  - 小便不利或涩痛
  - 舌老苔厚
  - 脉实有力

**虚实鉴别**：

| 项目 | 虚证 | 实证 |
|-----|------|------|
| 病程 | 长 | 短 |
| 体质 | 虚弱 | 壮实 |
| 精神 | 萎靡 | 烦躁 |
| 声音 | 低微 | 高亢 |
| 疼痛 | 喜按 | 拒按 |
| 舌象 | 淡或红少苔 | 老苔厚 |
| 脉象 | 虚 | 实 |

### 3.5 阴阳辨证

**阳证**：
- 包括：表证、热证、实证
- 表现：兴奋、躁动、亢进
- 舌象：舌红苔黄
- 脉象：浮、数、洪、滑、实

**阴证**：
- 包括：里证、寒证、虚证
- 表现：抑制、沉静、衰退
- 舌象：舌淡苔白
- 脉象：沉、迟、细、弱、虚

## 四、脏腑辨证

### 4.1 脏腑辨证的概念

**脏腑辨证**：根据脏腑的生理病理特点，分析疾病证候的辨证方法。

### 4.2 常见脏腑证候

#### 心病证候

| 证候 | 主要表现 |
|-----|---------|
| 心气虚 | 心悸，气短，自汗，活动后加重 |
| 心血虚 | 心悸，失眠，多梦，面色萎黄 |
| 心阳虚 | 心悸，畏寒，肢冷，面色㿠白 |
| 心火亢盛 | 心烦，失眠，口舌生疮，小便短赤 |
| 心脉瘀阻 | 胸闷，心痛，舌质紫暗 |

#### 肝病证候

| 证候 | 主要表现 |
|-----|---------|
| 肝气郁结 | 情志抑郁，胸胁胀痛，善太息 |
| 肝火上炎 | 头痛眩晕，面红目赤，口苦 |
| 肝血不足 | 眩晕耳鸣，面色无华，爪甲不荣 |
| 肝阳上亢 | 头晕目眩，腰膝酸软，头重脚轻 |

#### 脾病证候

| 证候 | 主要表现 |
|-----|---------|
| 脾气虚 | 食少，腹胀，大便溏薄，神疲乏力 |
| 脾阳虚 | 食少，腹痛喜温，四肢不温 |
| 脾虚湿盛 | 头身困重，脘腹胀满，舌苔厚腻 |

#### 肺病证候

| 证候 | 主要表现 |
|-----|---------|
| 肺气虚 | 咳嗽无力，气短喘促，自汗 |
| 肺阴虚 | 干咳少痰，潮热盗汗，舌红少苔 |
| 风寒束肺 | 咳嗽，痰稀色白，鼻塞流清涕 |
| 风热犯肺 | 咳嗽，痰黄稠，咽喉肿痛 |

#### 肾病证候

| 证候 | 主要表现 |
|-----|---------|
| 肾气虚 | 腰膝酸软，神疲乏力，耳鸣 |
| 肾阳虚 | 腰膝冷痛，畏寒肢冷，阳痿早泄 |
| 肾阴虚 | 腰膝酸软，眩晕耳鸣，潮热盗汗 |

## 五、辨证步骤

### 5.1 辨证思路

```
1. 收集资料（四诊）
   ↓
2. 辨别八纲（阴阳表里寒热虚实）
   ↓
3. 确定病位（脏腑经络）
   ↓
4. 明确病性（寒热虚实）
   ↓
5. 综合判断（证候名称）
```

### 5.2 辨证举例

**例 1：感冒**

| 项目 | 内容 |
|-----|------|
| 症状 | 恶寒重，发热轻，无汗，头痛，鼻塞流清涕 |
| 舌象 | 舌淡红，苔薄白 |
| 脉象 | 脉浮紧 |
| 八纲 | 表证、寒证、实证 |
| 证候 | 风寒束表证 |

**例 2：胃痛**

| 项目 | 内容 |
|-----|------|
| 症状 | 胃脘隐痛，喜温喜按，食少便溏 |
| 舌象 | 舌淡，苔白 |
| 脉象 | 脉弱 |
| 八纲 | 里证、寒证、虚证 |
| 证候 | 脾胃虚寒证 |
