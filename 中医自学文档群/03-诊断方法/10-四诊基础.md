# 10 四诊基础

> 望闻问切——中医诊断的基本方法

## 一、学习目标

- 了解四诊的基本概念
- 掌握望诊、闻诊、问诊的基本方法
- 为学习舌诊、脉诊打下基础

---

## 二、四诊概述

### 2.1 什么是四诊

**四诊**：望、闻、问、切四种诊断疾病的方法。

**四诊合参**：四种方法综合运用，不可偏废。

> "善诊者，察色按脉，先别阴阳。"  
> ——《素问·阴阳应象大论》

### 2.2 四诊的意义

| 诊法 | 作用 |
|-----|------|
| 望诊 | 观察外在表现 |
| 闻诊 | 听声音、嗅气味 |
| 问诊 | 了解病史症状 |
| 切诊 | 切脉、按诊 |

## 三、望诊

### 3.1 望诊的概念

**望诊**：医生通过观察患者全身和局部表现来诊断疾病的方法。

### 3.2 望神

**神**：生命活动的外在表现。

| 状态 | 表现 | 临床意义 |
|-----|------|---------|
| 得神 | 目光明亮，神志清晰，反应灵敏，语言清晰 | 正气充足，病情轻浅 |
| 少神 | 目光乏神，精神不振，思维迟钝 | 正气不足 |
| 失神 | 目光晦暗，神志昏糊，反应迟钝，语无伦次 | 正气大伤，病情危重 |
| 假神 | 久病重病突然精神转佳 | 临终前回光返照 |

### 3.3 望色

**五色主病**：

| 面色 | 主病 | 说明 |
|-----|------|------|
| 青 | 寒、痛、瘀、风 | 气血瘀滞 |
| 赤 | 热 | 热盛气血涌 |
| 黄 | 湿、虚 | 脾虚湿蕴 |
| 白 | 寒、虚、失血 | 气血不足 |
| 黑 | 寒、痛、瘀、水 | 肾虚水泛 |

### 3.4 望形态

| 形态 | 主病 |
|-----|------|
| 壮实 | 实证 |
| 瘦弱 | 虚证 |
| 喜蜷卧 | 寒证、虚证 |
| 喜伸展 | 热证、实证 |
| 水肿 | 水液停聚 |
| 消瘦 | 阴血不足 |

### 3.5 望头面五官

| 部位 | 异常表现 | 主病 |
|-----|---------|------|
| 头 | 囟门凹陷 | 津液不足 |
|  | 囟门高突 | 热盛 |
| 目 | 目赤 | 肝火 |
|  | 目黄 | 黄疸 |
|  | 目窠肿 | 水肿 |
| 鼻 | 鼻流清涕 | 风寒 |
|  | 鼻流浊涕 | 风热 |
|  | 鼻翼煽动 | 肺热 |
| 口唇 | 唇色淡白 | 血虚 |
|  | 唇色红赤 | 热盛 |
|  | 口角歪斜 | 中风 |

## 四、闻诊

### 4.1 闻诊的概念

**闻诊**：通过听声音和嗅气味来诊断疾病的方法。

### 4.2 听声音

| 声音 | 异常表现 | 主病 |
|-----|---------|------|
| 语言 | 语声高亢洪亮 | 实证、热证 |
|  | 语声低微无力 | 虚证、寒证 |
|  | 谵语 | 热扰心神 |
|  | 郑声 | 心气大伤 |
| 呼吸 | 呼吸气粗 | 实证 |
|  | 呼吸气微 | 虚证 |
|  | 喘 | 肺肾气虚或痰浊阻肺 |
|  | 哮 | 痰浊阻肺 |
| 咳嗽 | 咳声重浊 | 实证 |
|  | 咳声低微 | 虚证 |
|  | 干咳无痰 | 燥邪犯肺或肺阴虚 |
| 呕吐 | 吐势急迫 | 实证、热证 |
|  | 吐势徐缓 | 虚证、寒证 |

### 4.3 嗅气味

| 气味 | 异常表现 | 主病 |
|-----|---------|------|
| 口臭 | 气味臭秽 | 胃热 |
| 汗味 | 汗出腥臭 | 湿热 |
| 痰涕味 | 腥臭 | 热毒 |
| 二便味 | 臭秽 | 热证 |
|  | 腥臭 | 寒证 |

## 五、问诊

### 5.1 问诊的概念

**问诊**：医生询问患者或陪诊者，了解疾病发生、发展、治疗经过及现在症状的方法。

### 5.2 问诊的主要内容

#### 一问寒热

| 类型 | 表现 | 主病 |
|-----|------|------|
| 恶寒发热 | 恶寒重，发热轻 | 风寒表证 |
|  | 发热重，恶寒轻 | 风热表证 |
| 但寒不热 | 畏寒肢冷 | 里寒证 |
| 但热不寒 | 壮热 | 里热实证 |
|  | 潮热 | 阴虚或阳明腑实 |
| 寒热往来 | 寒热交替 | 少阳证 |

#### 二问汗

| 类型 | 表现 | 主病 |
|-----|------|------|
| 无汗 | 表寒证 | 寒邪束表 |
| 有汗 | 表热证 | 热邪伤津 |
| 自汗 | 白天汗出，活动后加重 | 气虚、阳虚 |
| 盗汗 | 睡时汗出，醒后汗止 | 阴虚 |
| 大汗 | 汗出如油 | 亡阳或亡阴 |
| 头汗 | 仅头部出汗 | 上焦热盛或湿热 |
| 半身汗 | 一侧身体出汗 | 气血运行不畅 |

#### 三问疼痛

| 类型 | 表现 | 主病 |
|-----|------|------|
| 性质 | 胀痛 | 气滞 |
|  | 刺痛 | 血瘀 |
|  | 冷痛 | 寒证 |
|  | 灼痛 | 热证 |
|  | 重痛 | 湿邪 |
|  | 隐痛 | 虚证 |
| 部位 | 头痛 | 外感或内伤 |
|  | 胸痛 | 心肺病变 |
|  | 胁痛 | 肝胆病变 |
|  | 胃脘痛 | 胃病 |
|  | 腹痛 | 脾胃或肠道病变 |
|  | 腰痛 | 肾病或腰肌病变 |

#### 四问饮食

| 类型 | 表现 | 主病 |
|-----|------|------|
| 食欲 | 食欲减退 | 脾胃虚弱 |
|  | 消谷善饥 | 胃火亢盛 |
|  | 饥不欲食 | 胃阴不足 |
| 口味 | 口淡无味 | 脾胃虚弱 |
|  | 口苦 | 肝胆火旺 |
|  | 口甜 | 脾胃湿热 |
|  | 口酸 | 肝胃不和 |
|  | 口咸 | 肾虚 |
| 口渴 | 口渴喜冷饮 | 热盛伤津 |
|  | 口渴喜热饮 | 寒证或津液不布 |
|  | 口不渴 | 寒证或津未伤 |

#### 五问二便

| 类型 | 表现 | 主病 |
|-----|------|------|
| 大便 | 便秘 | 热结或津亏 |
|  | 泄泻 | 脾虚或湿盛 |
|  | 便溏 | 脾虚湿盛 |
|  | 脓血便 | 湿热痢疾 |
| 小便 | 尿清长 | 寒证 |

#### 六问睡眠

| 类型 | 表现 | 主病 |
|-----|------|------|
| 失眠 | 入睡困难 | 心肾不交 |
|  | 易醒 | 心脾两虚 |
|  | 多梦 | 心肝血虚 |
| 嗜睡 | 困倦嗜睡 | 脾虚湿盛 |
|  | 昏睡 | 痰蒙心神 |

#### 七问妇女

- 月经：周期、量、色、质
- 带下：量、色、质、味

> 一问寒热二问汗，三问疼痛四问便，  
> 五问饮食六问胸，七聋八渴俱当辨，

## 七、四诊合参

### 7.1 四诊合参的意义

**四诊合参**：望、闻、问、切四种方法综合运用，全面收集病情资料。

**原因**：
- 每种诊法都有其局限性
- 病情复杂多变
- 避免片面性

### 7.2 四诊合参的应用

```
望诊 → 观察外在表现
闻诊 → 听声音、嗅气味
问诊 → 了解病史症状
切诊 → 切脉、按诊
    ↓
综合分析 → 辨证论治
```
