# 06 藏象学说

> 五脏六腑的功能与相互关系

## 一、学习目标

- 掌握五脏的主要功能
- 熟悉六腑的功能特点
- 理解脏腑之间的表里关系
- 能够运用藏象理论分析健康问题

---

## 二、藏象学说概述

### 2.1 什么是藏象

**藏象**："藏"指藏于体内的内脏，"象"指表现于外的生理、病理现象。

> "藏居于内，形见于外。"

**核心要点**：
- 通过外在表现推知内在脏腑功能
- 脏腑功能活动的外在反映
- 中医的脏腑不同于解剖学器官

### 2.2 脏腑分类

| 分类 | 内容 | 功能特点 |
|-----|------|---------|
| 五脏 | 心、肝、脾、肺、肾 | 藏精气而不泻 |
| 六腑 | 胆、胃、小肠、大肠、膀胱、三焦 | 传化物而不藏 |
| 奇恒之腑 | 脑、髓、骨、脉、胆、女子胞 | 形似腑，功能似脏 |

## 三、五脏功能详解

### 3.1 心

#### 基本属性

| 属性 | 内容 |
|-----|------|
| 五行 | 火 |
| 阴阳 | 阳中之阳 |
| 季节 | 夏 |
| 色味 | 赤、苦 |
| 官窍 | 舌 |
| 形体 | 脉 |
| 情志 | 喜 |
| 汗液 | 汗 |

#### 主要功能

**① 心主血脉**

- **含义**：心推动血液在脉中运行
- **条件**：
  - 心气充沛
  - 血液充盈
  - 脉道通利
- **表现**：
  - 面色红润光泽
  - 舌色淡红润泽
  - 脉象和缓有力
  - 精力充沛

**② 心主神明**

- **含义**：心主宰精神、意识、思维活动
- **地位**：心为"君主之官"，主宰生命活动
- **表现**：
  - 神志清晰
  - 思维敏捷
  - 反应灵敏
  - 睡眠良好

#### 病理表现

| 病机 | 表现 |
|-----|------|
| 心气虚 | 心悸、气短、自汗、活动后加重 |
| 心血虚 | 心悸、失眠、多梦、面色萎黄 |
| 心阳虚 | 心悸、畏寒、肢冷、面色㿠白 |
| 心火亢盛 | 心烦、失眠、口舌生疮、小便短赤 |
| 心脉瘀阻 | 胸闷、心痛、舌质紫暗 |

---

### 3.2 肝

#### 基本属性

| 属性 | 内容 |
|-----|------|
| 五行 | 木 |
| 阴阳 | 阴中之阳 |
| 季节 | 春 |
| 色味 | 青、酸 |
| 官窍 | 目 |
| 形体 | 筋 |
| 情志 | 怒 |
| 体液 | 泪 |

#### 主要功能

**① 肝主疏泄**

- **含义**：肝保持气机疏通畅达
- **作用**：
  - 调畅气机：促进气血运行
  - 促进消化：协助脾胃运化
  - 调畅情志：保持情绪舒畅
  - 调节生殖：影响月经、排精
- **表现**：
  - 情绪舒畅
  - 消化良好
  - 月经正常
  - 气机调畅

**② 肝主藏血**

- **含义**：肝贮藏和调节血液
- **作用**：
  - 贮藏血液：调节血量
  - 防止出血：统摄血液
- **表现**：
  - 目得血而能视
  - 足得血而能步
  - 掌得血而能握
  - 指得血而能摄

#### 病理表现

| 病机 | 表现 |
|-----|------|
| 肝气郁结 | 情志抑郁、胸胁胀痛、善太息 |
| 肝火上炎 | 头痛眩晕、面红目赤、口苦 |
| 肝血不足 | 眩晕耳鸣、面色无华、爪甲不荣 |
| 肝阳上亢 | 头晕目眩、腰膝酸软、头重脚轻 |
| 肝风内动 | 眩晕、抽搐、震颤、中风 |

### 3.3 脾

#### 基本属性

| 属性 | 内容 |
|-----|------|
| 五行 | 土 |
| 阴阳 | 阴中之至阴 |
| 季节 | 长夏 |
| 色味 | 黄、甘 |
| 官窍 | 口 |
| 形体 | 肉 |
| 情志 | 思 |
| 体液 | 涎 |

#### 主要功能

**① 脾主运化**

- **含义**：脾消化、转运水谷精微
- **作用**：
  - 运化水谷：消化吸收食物
  - 运化水液：代谢水液
- **地位**：脾为"后天之本"，"气血生化之源"
- **表现**：
  - 食欲良好
  - 消化正常
  - 气血充足
  - 肌肉丰满

**② 脾主统血**

- **含义**：脾统摄血液在脉中运行
- **作用**：防止血液溢出脉外
- **表现**：无出血症状

**③ 脾主升清**

- **含义**：脾将水谷精微上输于心肺
- **作用**：
  - 上输营养
  - 升举内脏
- **表现**：
  - 头脑清晰
  - 内脏位置正常

#### 病理表现

| 病机 | 表现 |
|-----|------|
| 脾气虚 | 食少、腹胀、大便溏薄、神疲乏力 |
| 脾阳虚 | 食少、腹痛喜温喜按、四肢不温 |
| 脾不统血 | 便血、尿血、肌衄、月经淋漓 |
| 中气下陷 | 脱肛、子宫脱垂、胃下垂 |
| 脾虚湿盛 | 头身困重、脘腹胀满、舌苔厚腻 |

### 3.4 肺

#### 基本属性

| 属性 | 内容 |
|-----|------|
| 五行 | 金 |
| 阴阳 | 阳中之阴 |
| 季节 | 秋 |
| 色味 | 白、辛 |
| 官窍 | 鼻 |
| 形体 | 皮 |
| 情志 | 忧 |
| 体液 | 涕 |

#### 主要功能

**① 肺主气司呼吸**

- **含义**：肺主呼吸之气和一身之气
- **作用**：
  - 主呼吸：气体交换
  - 主一身之气：生成宗气
- **表现**：
  - 呼吸均匀
  - 声音洪亮
  - 气力充足

**② 肺主宣发肃降**

- **宣发**：肺气向上向外
  - 排出浊气
  - 输布津液
  - 宣发卫气
- **肃降**：肺气向下向内
  - 吸入清气
  - 下输津液
  - 清洁呼吸道
- **表现**：
  - 呼吸通畅
  - 水道通调

**③ 肺主通调水道**

- **含义**：肺调节水液代谢
- **作用**：宣发肃降调节水液运行
- **称法**：肺为"水之上源"

**④ 肺主朝百脉**

- **含义**：全身血液通过经脉汇聚于肺
- **作用**：辅助心脏推动血液运行

#### 病理表现

| 病机 | 表现 |
|-----|------|
| 肺气虚 | 咳嗽无力、气短喘促、自汗 |
| 肺阴虚 | 干咳少痰、痰中带血、潮热盗汗 |
| 风寒束肺 | 咳嗽、痰稀色白、鼻塞流清涕 |
| 风热犯肺 | 咳嗽、痰黄稠、咽喉肿痛 |
| 肺失宣降 | 咳嗽、气喘、胸闷 |

### 3.5 肾

#### 基本属性

| 属性 | 内容 |
|-----|------|
| 五行 | 水 |
| 阴阳 | 阴中之阴 |
| 季节 | 冬 |
| 色味 | 黑、咸 |
| 官窍 | 耳 |
| 形体 | 骨 |
| 情志 | 恐 |
| 体液 | 唾 |

#### 主要功能

**① 肾主藏精**

- **含义**：肾贮藏先天之精和后天之精
- **分类**：
  - 先天之精：禀受于父母
  - 后天之精：来源于水谷
- **作用**：
  - 促进生长发育
  - 促进生殖
  - 濡养脏腑
- **表现**：
  - 生长发育正常
  - 生殖功能正常
  - 精力充沛

**② 肾主水**

- **含义**：肾调节水液代谢
- **作用**：
  - 气化作用：蒸腾气化
  - 开阖作用：调节尿量
- **地位**：肾为"水脏"，主水液代谢

**③ 肾主纳气**

- **含义**：肾摄纳肺吸入的清气
- **作用**：保持呼吸深度
- **表现**：呼吸均匀深沉

**④ 肾主骨生髓**

- **含义**：肾精滋养骨骼和骨髓
- **作用**：
  - 滋养骨骼
  - 生髓充脑
  - 化生血液
- **表现**：
  - 骨骼强壮
  - 牙齿坚固
  - 头脑清晰

#### 病理表现

| 病机 | 表现 |
|-----|------|
| 肾气虚 | 腰膝酸软、神疲乏力、耳鸣 |
| 肾阳虚 | 腰膝冷痛、畏寒肢冷、阳痿早泄 |
| 肾阴虚 | 腰膝酸软、眩晕耳鸣、潮热盗汗 |
| 肾精不足 | 发育迟缓、早衰、不孕不育 |
| 肾不纳气 | 呼多吸少、动则气喘 |

## 四、六腑功能

### 4.1 六腑概述

| 六腑 | 主要功能 |
|-----|---------|
| 胆 | 贮存和排泄胆汁，主决断 |
| 胃 | 受纳腐熟水谷，主通降 |
| 小肠 | 受盛化物，泌别清浊 |
| 大肠 | 传化糟粕，主津 |
| 膀胱 | 贮存和排泄尿液 |
| 三焦 | 通行元气，运行水液 |

**六腑共同特点**：传化物而不藏，以通为用

### 4.2 胆

- **功能**：
  - 贮存胆汁
  - 排泄胆汁助消化
  - 主决断（精神活动）
- **特点**：既属六腑，又属奇恒之腑

### 4.3 胃

- **功能**：
  - 受纳水谷：接受和容纳食物
  - 腐熟水谷：初步消化
- **特点**：胃为"水谷之海"，"后天之本"
- **生理**：胃气宜降，喜润恶燥

### 4.4 小肠

- **功能**：
  - 受盛化物：接受胃传来的食糜
  - 泌别清浊：吸收精华，分离糟粕
- **特点**：小肠主液

### 4.5 大肠

- **功能**：传导糟粕，吸收水分
- **特点**：大肠主津

### 4.6 膀胱

- **功能**：贮存和排泄尿液
- **特点**：膀胱的气化依赖肾气

### 4.7 三焦

- **功能**：
  - 通行元气：元气运行的通道
  - 运行水液：水液代谢的通道
- **分部**：
  - 上焦：心肺，主宣发
  - 中焦：脾胃，主运化
  - 下焦：肝肾膀胱，主排泄

## 五、脏腑表里关系

### 5.1 五脏六腑的表里配合

| 脏（里） | 腑（表） | 经络联系 |
|---------|---------|---------|
| 心 | 小肠 | 手少阴心经 - 手太阳小肠经 |
| 肺 | 大肠 | 手太阴肺经 - 手阳明大肠经 |
| 脾 | 胃 | 足太阴脾经 - 足阳明胃经 |
| 肝 | 胆 | 足厥阴肝经 - 足少阳胆经 |
| 肾 | 膀胱 | 足少阴肾经 - 足太阳膀胱经 |

### 5.2 表里关系的应用

**生理**：
- 脏病及腑：肝病影响胆
- 腑病及脏：胃病影响脾

**治疗**：
- 脏病治腑：心火旺泻小肠
- 腑病治脏：便秘补肺
