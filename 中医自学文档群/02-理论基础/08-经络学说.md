## 二、经络系统概述

### 2.1 什么是经络

**经络**：运行气血、联络脏腑肢节、沟通内外上下的通路。

**经与络的区别**：

|  | 经 | 络 |
|---|---|---|
| 位置 | 纵行，深入 | 横行，浅表 |
| 大小 | 主干，较大 | 分支，细小 |
| 数量 | 较少 | 众多 |
| 分布 | 有固定路线 | 网络全身 |

### 2.2 经络系统的组成

```
经络系统
├── 经脉（主干）
│   ├── 十二经脉
│   ├── 奇经八脉
│   └── 十二经别
├── 络脉（分支）
│   ├── 十五络脉
│   ├── 孙络
│   └── 浮络
└── 连属部分
    ├── 十二经筋
    └── 十二皮部
```

## 三、十二经脉

### 3.1 十二经脉的命名

**命名规则**：手/足 + 阴/阳 + 脏腑

| 分类 | 经脉名称 | 属络脏腑 |
|-----|---------|---------|
| 手三阴经 | 手太阴肺经 | 属肺络大肠 |
|  | 手厥阴心包经 | 属心包络三焦 |
|  | 手少阴心经 | 属心络小肠 |
| 手三阳经 | 手阳明大肠经 | 属大肠络肺 |
|  | 手少阳三焦经 | 属三焦络心包 |
|  | 手太阳小肠经 | 属小肠络心 |
| 足三阴经 | 足太阴脾经 | 属脾络胃 |
|  | 足厥阴肝经 | 属肝络胆 |
|  | 足少阴肾经 | 属肾络膀胱 |
| 足三阳经 | 足阳明胃经 | 属胃络脾 |
|  | 足少阳胆经 | 属胆络肝 |
|  | 足太阳膀胱经 | 属膀胱络肾 |

### 3.2 十二经脉的走向

```
手三阴经：胸 → 手（从胸走手）
手三阳经：手 → 头（从手走头）
足三阳经：头 → 足（从头走足）
足三阴经：足 → 腹（从足走腹）
```

**规律**：
- 阴经上行，阳经下行
- 手经在上，足经在下

### 3.3 十二经脉的交接

**交接规律**：

| 交接部位 | 经脉 |
|---------|------|
| 手指端 | 手三阴经与手三阳经交接 |
| 头面部 | 手三阳经与足三阳经交接 |
| 足趾端 | 足三阳经与足三阴经交接 |
| 胸腹部 | 足三阴经与手三阴经交接 |

### 3.4 十二经脉的流注次序

```
肺经 → 大肠经 → 胃经 → 脾经 → 心经 → 小肠经
  ↑                                      ↓
肾经 ← 膀胱经 ← 胆经 ← 肝经 ← 心包经 ← 三焦经
```

**循环**：如环无端，周而复始

## 四、奇经八脉

### 4.1 奇经八脉的组成

| 经脉 | 主要功能 |
|-----|---------|
| 任脉 | 总任一身之阴，"阴脉之海" |
| 督脉 | 总督一身之阳，"阳脉之海" |
| 冲脉 | 调节十二经气血，"十二经之海" |
| 带脉 | 约束纵行经脉，"束带诸脉" |
| 阴维脉 | 维系一身之阴 |
| 阳维脉 | 维系一身之阳 |
| 阴跷脉 | 主下肢运动，司眼睑开合 |
| 阳跷脉 | 主下肢运动，司眼睑开合 |

### 4.2 任脉

- **循行**：腹正中线，会阴→下颌
- **功能**：
  - 总任一身之阴经
  - 调节月经，妊养胎儿
- **称法**："阴脉之海"，"任主胞胎"

### 4.3 督脉

- **循行**：背正中线，会阴→头顶→上唇
- **功能**：
  - 总督一身之阳经
  - 调节脑髓，主生殖
- **称法**："阳脉之海"

### 4.4 冲脉

- **循行**：夹脐两侧，上行至头，下行至足
- **功能**：
  - 调节十二经气血
  - 主生殖
- **称法**："十二经之海"，"血海"

### 4.5 带脉

- **循行**：绕腰一周
- **功能**：约束纵行经脉

## 六、经络在诊断治疗中的应用

### 6.1 诊断应用

**循经诊察**：
- 沿经脉循行路线寻找压痛点
- 观察皮肤颜色、温度变化

**例**：
- 肺经异常：中府、尺泽压痛
- 胃病：足三里压痛
- 肝病：太冲压痛

### 6.2 治疗应用

**循经取穴**：
- 近部取穴：病变局部取穴
- 远部取穴：循经远取
- 辨证取穴：根据证候取穴

**例**：
- 头痛：太阳头痛取后溪，阳明头痛取合谷
- 胃痛：取足三里、中脘
- 咳嗽：取肺俞、尺泽
