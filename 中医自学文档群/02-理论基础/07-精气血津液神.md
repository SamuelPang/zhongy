# 07 精气血津液神

> 生命活动的物质基础

## 一、学习目标

- 掌握精、气、血、津液、神的概念和功能
- 理解它们之间的相互关系
- 能够运用理论分析健康问题

---

## 二、精

### 2.1 精的概念

**精**：构成人体和维持生命活动的基本物质。

### 2.2 精的分类

| 分类 | 来源 | 功能 |
|-----|------|------|
| 先天之精 | 禀受于父母 | 促进生长发育，生殖 |
| 后天之精 | 来源于水谷 | 濡养脏腑，补充先天 |

### 2.3 精的功能

- **促进生长发育**：从幼年到成年到衰老
- **促进生殖**：繁衍后代
- **濡养脏腑**：滋养全身
- **化生气血**：生成气和血

---

## 三、气

### 3.1 气的概念

**气**：构成人体和维持生命活动的精微物质，具有推动、温煦等作用。

### 3.2 气的分类

| 分类 | 生成 | 分布 | 功能 |
|-----|------|------|------|
| 元气 | 肾精化生 | 全身 | 生命原动力 |
| 宗气 | 肺吸入清气 + 水谷精气 | 胸中 | 司呼吸，行气血 |
| 营气 | 水谷精气 | 脉中 | 营养全身，化生血液 |
| 卫气 | 水谷精气 | 脉外 | 护卫肌表，温养脏腑 |

### 3.3 气的功能

| 功能 | 说明 |
|-----|------|
| 推动 | 促进生长发育，推动脏腑功能，推动血液运行 |
| 温煦 | 维持体温，温煦脏腑 |
| 防御 | 抵御外邪，驱邪外出 |
| 固摄 | 统摄血液，固摄津液，固摄精液 |
| 气化 | 促进物质代谢和转化 |

### 3.4 气的运动

**气机**：气的升降出入运动

| 运动形式 | 脏腑 | 说明 |
|---------|------|------|
| 升 | 脾、肝 | 清气上升 |
| 降 | 肺、胃、大肠 | 浊气下降 |
| 出 | 全身 | 气向外 |
| 入 | 全身 | 气向内 |

**气机失调**：
| 类型 | 表现 |
|-----|------|
| 气滞 | 气的运行不畅，胀痛 |
| 气逆 | 上升太过，咳喘、呕吐 |
| 气陷 | 上升不及，脱肛、内脏下垂 |
| 气闭 | 气郁闭于内，昏厥 |
| 气脱 | 气大量外脱，虚脱 |

---

## 四、血

### 4.1 血的概念

**血**：运行于脉中的红色液体，具有营养和滋润作用。

### 4.2 血的生成

```
水谷精微 → 脾胃运化 → 营气 + 津液 → 心肺 → 化赤为血
                          ↓
                    肾精化血（辅助）
```

### 4.3 血的功能

| 功能 | 说明 |
|-----|------|
| 营养滋润 | 濡养脏腑、四肢百骸 |
| 神志活动 | 血是神志活动的物质基础 |

### 4.4 血的运行

**影响因素**：
- 心气推动
- 肺气辅佐
- 肝气疏泄
- 脾气统摄

**血行异常**：
| 类型 | 表现 |
|-----|------|
| 血虚 | 血液不足，面色萎黄 |
| 血瘀 | 运行不畅，刺痛、肿块 |
| 血热 | 热入血分，出血、斑疹 |
| 出血 | 溢出脉外，各种出血 |

---

## 五、津液

### 5.1 津液的概念

**津液**：机体正常水液的总称。

**津与液的区别**：

|  | 津 | 液 |
|---|---|---|
| 性质 | 清稀 | 稠厚 |
| 分布 | 体表、肌肉 | 关节、脏腑、脑髓 |
| 功能 | 滋润 | 濡养 |

### 5.2 津液的代谢

```
摄入 → 脾胃运化 → 肺宣发肃降 → 肾气化 → 排出
                    ↓              ↓
                 输布全身      尿液
```

**相关脏腑**：
- 脾：运化水液
- 肺：通调水道
- 肾：主水
- 膀胱：贮存排泄尿液
- 三焦：水液通道

### 5.3 津液异常

| 类型 | 表现 |
|-----|------|
| 津液不足 | 口干、皮肤干燥、便秘 |
| 水液停聚 | 水肿、痰饮、湿浊 |

## 六、神

### 6.1 神的概念

**神**：生命活动的外在表现，也包括精神意识思维活动。

### 6.2 神的分类

| 分类 | 说明 |
|-----|------|
| 元神 | 先天之神，与生俱来 |
| 识神 | 后天之神，精神意识 |

### 6.3 神的功能

- 主宰生命活动
- 主宰精神意识
- 反映健康状况

### 6.4 得神与失神

| 状态 | 表现 |
|-----|------|
| 得神 | 目光明亮，神志清晰，反应灵敏 |
| 少神 | 目光乏神，精神不振 |
| 失神 | 目光晦暗，神志昏糊，反应迟钝 |

## 七、精气血津液神的关系

### 7.1 气与血

**关系**：
> "气为血之帅，血为气之母"

**气为血之帅**：
- 气能生血：气的运动化生血液
- 气能行血：气推动血液运行
- 气能摄血：气统摄血液在脉中

**血为气之母**：
- 血能载气：气依附于血
- 血能养气：血滋养气

### 7.2 气与津液

**关系**：
- 气能生津：气推动津液生成
- 气能行津：气推动津液运行
- 气能摄津：气固摄津液
- 津能载气：气依附于津液
- 津能生气：津液化生气

### 7.3 精与气

**关系**：
- 精能化气：精是气的物质基础
- 气能生精：气促进精的生成

### 7.4 精与血

**关系**：
> "精血同源"

- 精能化血：精是生血的基础
- 血能养精：血滋养精

### 7.5 血与津液

**关系**：
> "津血同源"

- 津液是血液的组成部分
- 血液可化为津液

**临床意义**：
- 失血者勿发汗（汗为津液）
- 多汗者勿破血

## 八、学习要点

### 重点掌握

1. ✅ 气的四种分类（元气、宗气、营气、卫气）
2. ✅ 气的五大功能（推动、温煦、防御、固摄、气化）
3. ✅ 气与血的关系（气为血之帅，血为气之母）
4. ✅ 津液代谢的相关脏腑

### 难点提示

⚠️ **四种气的区别**：
- 元气：先天之气，生命原动力
- 宗气：积于胸中，司呼吸行气血
- 营气：行于脉中，营养全身
- 卫气：行于脉外，护卫肌表

⚠️ **气机失调**：
- 气滞：运行不畅
- 气逆：上升太过
- 气陷：上升不及
- 气闭：郁闭于内
- 气脱：大量外脱
