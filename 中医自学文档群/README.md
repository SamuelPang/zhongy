# 中医自学文档群

> 从《周易》出发，循序渐进学习中医理论的完整指南

## 📚 文档群简介

本套文档专为普通人自学中医设计，从《周易》哲学基础开始，循序渐进地构建完整的中医理论体系，最终达到养生保健、常见病自诊自疗的应用目标。

### 设计理念

- **医易同源**：从《周易》阴阳五行出发，理解中医理论本源
- **循序渐进**：分六个层级，从基础到经典，难度逐步提升
- **理论结合实践**：每个阶段都包含实践应用指导
- **安全第一**：强调自学以养生保健为主，疾病治疗需专业指导

根据您的学习目标，可选择不同的学习路径：

### 路径一：养生保健（入门级）

**适合人群**：希望了解中医养生知识，改善日常生活质量

**学习文档**：
```
01 → 02 → 03 → 04 → 05 → 06 → 16 → 19 → 20
```

**预期时间**：3-6 个月

## ⚠️ 重要说明

### 学习建议

1. **循序渐进**：不要跳级学习，打好基础最重要
2. **理论结合实践**：学习过程中注意联系实际生活
3. **经典与教材并重**：教材打基础，经典求本源
4. **反复研读**：中医理论需要反复体悟，不是一蹴而就
5. **加入社群**：与其他学习者交流心得

### 安全提示

⚠️ **本套文档仅供自学养生保健参考，不可替代专业医疗**

- 涉及疾病治疗应咨询专业中医师
- 有毒药物、针灸等操作需专业指导
- 孕妇、儿童、老人用药需特别谨慎
- 急重症应立即就医，不可自行诊治
